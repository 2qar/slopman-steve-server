# Slopman Steve Server

Replacement backend for Hero Siege's legacy `data.win` HTTP endpoints.

Targets this Steam depot version of Hero Siege: `5746244942309633523`.

## Set up the old game client

1. Open the Steam console:
   - in a browser: `steam://open/console`
   - or in a terminal: `steam steam://open/console`
2. Download the old Hero Siege depot:
   ```text
   download_depot 269210 269211 5746244942309633523
   ```
3. Create `steam_appid.txt` containing `269210` next to `bin/Hero_Siege.exe`
   inside the depot download.
4. Add the old game to Steam: Games -> Add a Non-Steam Game to My Library ->
   Browse -> select `Hero_Siege.exe` from the depot download.

Do not copy the old files over an existing Hero Siege install; Steam tends to
re-pull the latest update on launch.

## Run

```sh
go run ./cmd/herosiege-server -addr :8080 -db herosiege.db
```

## Test

```sh
make check
```

## Point the game client at this backend

The legacy client's backend URL is hardcoded in `data.win`
(`global.networkaddress`, plus a standalone `ping.php` and the redeem-code
URL). Patch it with the UndertaleModTool script:

```sh
HERO_SIEGE_BACKEND_URL=http://localhost:8080/ scripts/patch-datawin-url.sh
```

Or in the UMT GUI: open `data.win`, then run
`scripts/umt_patch_url.csx` via Scripts -> Run script.

## Capturing a session

To record real game traffic, capture loopback traffic with Wireshark while
playing, save as `test_session.pcapng`, and ask an agent to convert the
captured requests into e2e tests.
